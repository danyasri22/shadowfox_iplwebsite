## 📌 Project Overview


The objective was to design and develop a comprehensive website dedicated to my favorite IPL team, serving as a central hub for fans to access team-related information, including match schedules, player profiles, statistics, and fan engagement features.

This website captures the spirit and excitement of supporting an IPL franchise through an immersive and responsive user interface.
